# 0.7.0 CacheEnvelope 开发中复测

- 日期：2026-11-24
- 对比：0.6.1 基线 vs 0.7.0 Phase 1 CacheEnvelope
- 环境：与 `0.6.1-baseline.md` 相同，SQLite + file cache + PHP built-in server
- 场景：B2 Local HIT，商品页 `/page-cache-test-product/`
- 方法：300 请求/轮，并发 10，5 轮中位数

## 1. 结果

| 指标 | 0.6.1 基线 | 0.7.0 CacheEnvelope | 变化 |
|---|---:|---:|---:|
| RPS | 237.91 | 244.01 | +2.56% |
| P50 | 38.426 ms | 36.912 ms | -3.94% |
| P95 | 64.494 ms | 63.579 ms | -1.42% |
| P99 | 79.760 ms | 80.027 ms | +0.33% |
| Local HIT cache reads | 5 | 3 | -2 |

## 2. 结论

- **读取次数目标已达成**：`LocalHitReadCountTest` 证明普通 HIT 只读 global、URL 和 envelope 三次；显式版本时一次。
- **P95 ≥15% 目标未达成**：当前 PHP built-in server 环境下 P95 只改善 1.42%。页面缓存命中仍受 Maho 启动、请求解析、context 计算和 PHP 框架开销限制。
- 减少 2 次 cache 读取的绝对收益很小，不能把 P95 目标建立在 CacheEnvelope 单项上。
- 0.7.0 Release Gate G9 继续保持未通过，等待 PHP-FPM + nginx + Redis 环境和完整场景 benchmark。
- 不应为了追求 15% 而取消版本校验或减少必要读取；正确性优先。
