# 0.8.0 Static Export 基准

> 状态：2026-11-25 完成
> 关联：[Static Export 部署](../deployment/static-export.md)、[0.6.1 基线](0.6.1-baseline.md)

## 方法

- 应用：SQLite + file cache + local 模式，静态导出开启。
- 页面：`/page-cache-test-product/`，先由 PHP 生成 `index.html` 和 `index.html.gz`。
- 代理：nginx 1.31 和 Caddy 2，配置见 `docs/deployment/static/`。
- 请求：300 请求/轮，并发 10，5 轮中位数，2 轮预热。
- 客户端：`docs/benchmark/run.mjs`，与 B0-B5 相同。
- 主机负载会影响绝对值；本次 nginx 和 Caddy 在同一窗口内测量，相对结论有效。

## 结果

| 场景 | RPS | P50 | P95 | P99 |
|---|---:|---:|---:|---:|
| B2 Local HIT（0.6.1 基线） | 237.91 | 38.426 ms | 64.494 ms | 79.760 ms |
| nginx Static Export | 5492.83 | 1.601 ms | 3.258 ms | 4.582 ms |
| Caddy Static Export | 4850.68 | 1.868 ms | 3.281 ms | 4.236 ms |

对比 B2：

| 场景 | RPS 倍数 | P95 改善 |
|---|---:|---:|
| nginx | 23.1x | -95.0% |
| Caddy | 20.4x | -94.9% |

## 目标

G9 的 Local HIT P95 ≥15% 已作为 0.7.0 Known issue 保留。Static Export 使用新的相对目标：

- P95 至少比 B2 Local HIT 低 80%。
- RPS 至少是 B2 Local HIT 的 5 倍。

nginx 和 Caddy 都通过。

## 复现

```bash
# 1. 生成静态文件
./maho config:set -s default -i 0 page_cache/general/mode local
./maho config:set -s default -i 0 page_cache/static/enabled 1
./maho cache:flush
curl -sS -o /dev/null http://localhost:8000/page-cache-test-product/

# 2. 启动 nginx 或 Caddy，配置见 docs/deployment/static/
# 3. 跑基准
node docs/benchmark/run.mjs \
  --label b5-static-nginx-0.8.0 \
  --url http://localhost:8085/page-cache-test-product/ \
  --requests 300 --concurrency 10 --rounds 5 --warmup 2 \
  > docs/benchmark/raw/0.8.0-b5-static-nginx.json
```

原始数据：

```text
docs/benchmark/raw/0.8.0-b5-static-nginx.json
docs/benchmark/raw/0.8.0-b5-static-caddy.json
```

## 说明

- 静态命中没有 `X-Maho-Cache`；nginx/Caddy 配置用 `X-Page-Cache: HIT-static` 标记。
- Caddy 的 `file_server` 会额外加一个 `Vary: Accept-Encoding`，与配置里的 `Vary: Accept-Encoding, Cookie` 并存，是正常的。
- 本次 nginx 比 0.6.1 的 B5 低，是因为配置增加了 store/session/query/method 判断和 header map，且主机负载不同。绝对值不作容量承诺；相对目标仍以同一窗口的 B2 为参照。
- 静态文件不经过 PHP，不返回 304；TTL 和失效由文件删除控制。
- 只支持单节点。多节点共享静态目录属于 FR-19。
