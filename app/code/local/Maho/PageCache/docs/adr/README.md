# 架构决策记录（ADR）

本目录记录 `Maho_PageCache` 模块的重大架构决策。编号从 0001 开始，文件名使用英文 slug，正文使用中文。

| 编号 | 标题 | 状态 |
|---|---|---|
| 0001 | 使用 Maho 原生实现，不移植 RockSolid 或 Cm_Diehard | 已接受 |
| 0002 | 三种后端模式分三期交付 | 已接受 |
| 0003 | 匿名 GET 跳过 session，并用 session cookie 做保守判定 | 已接受 |
| 0004 | tag 加版本失效，规则和配置按混合粒度处理 | 已接受 |
| 0005 | revalidating 使用版本 ETag 和渲染前 304 | 已接受 |
| 0006 | proxy 模式使用自定义 Vary 和通用 purge 契约 | 已接受；Vary 部分已被 ADR-0008 取代 |
| 0007 | 动态块打孔分两期实现 | 已接受 |
| 0008 | proxy 模式使用 Vary: Cookie，context 头只用于调试 | 已接受 |
| 0009 | local 模式把整页 HTML 存入 Symfony Cache | 已接受 |
| 0010 | 动态块用同一页面的 dynamic 请求，不做任意 block 重建 | 已接受 |
| 0011 | 预热使用公开 HTTP 请求 | 已接受 |
| 0012 | 第三期增加可选的静态文件导出层 | 已接受，第三期第一批 |
| 0013 | 第三期用数据库统计表和后台面板替代缓存计数器 | 已接受，第三期 |
| 0014 | 第三期增加 cron 预热和 purge 后 requeue | 已接受，第三期 |
| 0016 | 页面缓存使用原生 tag-aware cache 和 DB URL 索引 | 已接受，0.5.2 内部重构 |
| 0017 | proxy context 模式和 P1 缓存加固 | 已接受，0.5.3 |
| 0018 | P1 缓存性能和清理索引 | 已接受，0.5.3 |

新增 ADR 时复制 `_template.md`，顺序编号。已被取代的 ADR 不删除，状态改为“已被 ADR-NNNN 取代”。
